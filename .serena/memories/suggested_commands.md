# Suggested Commands
- `openspec list --json` to inspect active changes.
- `openspec status --change "<change>" --json` to inspect artifact progress for a change.
- `openspec instructions apply --change "<change>" --json` to get task implementation context.
- `openspec validate <change>` to validate a change after editing specs/tasks.
- `openspec archive <change>` to archive a completed change and sync main specs.
- `rg --files .` to list repository files quickly.
- `rg "pattern" <path>` to search docs/specs.
- `sed -n 'start,endp' <file>` to inspect targeted file sections on Darwin/zsh.
